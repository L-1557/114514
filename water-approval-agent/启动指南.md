# 涉水审批系统 - 完整启动指南

## ✅ 自动启动（推荐）

### Python AI 服务（已自动启动）
运行以下脚本即可自动启动 Python AI 服务：
```bash
start.bat
```
服务地址：http://localhost:8001

## 📦 安装 Maven（启动 Java 后端必需）

### Windows 安装 Maven

1. **下载 Maven**
   - 访问：https://maven.apache.org/download.cgi
   - 下载：`apache-maven-3.9.x-bin.zip`

2. **解压到目录**
   - 例如：`C:\Program Files\Apache\maven`

3. **添加环境变量**
   - 右键"此电脑" → "属性" → "高级系统设置"
   - "环境变量" → "系统变量" → "Path" → "编辑"
   - 添加：`C:\Program Files\Apache\maven\bin`

4. **验证安装**
   ```bash
   mvn -version
   ```

### 或使用 Chocolatey 安装
```bash
choco install maven
```

## 🚀 手动启动服务

### 1. 启动 Python AI 服务
```bash
cd python-ai-service
python main_simple.py
```
服务地址：http://localhost:8001

### 2. 启动 Java 后端（需要 Maven）
```bash
cd java-backend
mvn spring-boot:run
```
服务地址：http://localhost:8080

## 🖥️ 使用 IDE 启动（无需 Maven 命令行）

### IntelliJ IDEA
1. 打开 `java-backend` 文件夹
2. 右键 `WaterApprovalApplication.java`
3. 选择 "Run 'WaterApprovalApplication'"

### Eclipse
1. File → Import → Existing Maven Projects
2. 选择 `java-backend` 文件夹
3. 右键 `WaterApprovalApplication.java`
4. Run As → Java Application

## 🔧 常见问题解决

### Q: Python 服务无法启动？
A: 检查端口 8001 是否被占用，或修改 `main_simple.py` 中的 `PORT` 变量

### Q: Java 后端启动失败？
A: 
1. 确保已安装 JDK 17+
2. 确保已安装 Maven
3. 检查 `JAVA_HOME` 和 `MAVEN_HOME` 环境变量

### Q: 端口被占用？
A: 
- Python: 修改 `main_simple.py` 第 12 行的 `PORT = 8001`
- Java: 修改 `application.properties` 中的 `server.port`
