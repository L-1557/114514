## 🔧 常见问题解决

### 问题 1：Python 未安装

**错误信息**：
```
[错误] Python 未安装或未配置到 PATH
```

**解决方案**：

1. **下载 Python**
   - 访问：https://www.python.org/downloads/
   - 下载 Python 3.8 或更高版本

2. **安装 Python**
   - 运行安装程序
   - ✅ **重要**：勾选 "Add Python to PATH"

3. **验证安装**
   ```bash
   python --version
   ```

---

### 问题 2：端口被占用

**错误信息**：
```
OSError: [WinError 10048] 端口 8003 已被占用
```

**解决方案**：

**方案 A：杀死占用端口的进程**

1. 查找占用端口的进程
   ```bash
   netstat -ano | findstr :8003
   ```

2. 假设 PID 为 12345，杀死进程
   ```bash
   taskkill /F /PID 12345
   ```

3. 重新启动 AI 服务

**方案 B：修改端口**

1. 编辑 `main_simple.py` 第 12 行
   ```python
   PORT = 8004  # 改为其他端口
   ```

2. 编辑 `AppConfig.java` 第 28 行
   ```java
   .baseUrl("http://localhost:8004")
   ```

3. 重新启动 AI 服务

---

### 问题 3：找不到文件

**错误信息**：

## 📞 常见问题 FAQ

### Q1: AI 服务必须一直运行吗？
A: 是的，使用 AI 审查功能时需要保持运行。

### Q2: 可以关闭启动窗口吗？
A: 不能，关闭窗口会停止服务。

### Q3: 如何停止 AI 服务？
A: 在启动窗口按 Ctrl+C。

### Q4: 开机自动启动？
A: 可以将启动脚本添加到开机启动项。

### Q5: 可以在其他机器上运行吗？
A: 可以，修改 IP 地址和端口配置即可。
