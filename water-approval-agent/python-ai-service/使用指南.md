## 🔧 常见问题

### ❌ 问题 1：端口被占用

**错误信息**：
```
OSError: [WinError 10048] 通常每个套接字地址 (协议/网络地址/端口) 只允许使用一次
```

**解决方案**：
1. 打开 `main_simple.py`
2. 找到第 13 行：`PORT = 8003`
3. 修改为其他端口，如：`PORT = 8004`
4. 保存并重新启动

### ❌ 问题 2：Python 未找到

**错误信息**：
```
'python' 不是内部或外部命令
```

**解决方案**：
1. 安装 Python 3.8 或更高版本
2. 将 Python 添加到系统 PATH
3. 重启命令行

### ❌ 问题 3：服务无法访问

**解决方案**：
1. 检查防火墙设置
2. 确认服务已启动（查看命令行输出）
3. 检查端口号是否正确
