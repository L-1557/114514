## 🔧 常见问题

### 问题 1：Java 版本太低

**错误**：
```
Unsupported class file major version
```

**解决**：
1. 下载 JDK 17+：https://adoptium.net/
2. 安装后重启命令行
3. 重新运行启动脚本

---

### 问题 2：Maven 下载依赖失败

**错误**：
```
Could not resolve dependencies
```

**解决**：
1. 检查网络连接
2. 配置 Maven 镜像（pom.xml）
3. 或使用 IntelliJ IDEA 自动下载

---

### 问题 3：端口被占用

**错误**：
```
Port 8080 was already in use
```

**解决**：
```bash
# 查找占用端口的进程
netstat -ano | findstr :8080

# 杀死进程
taskkill /F /PID [进程 ID]
```

---

### 问题 4：Python AI 服务未启动

**错误**：
```
AI 审查失败：Connection refused
```

**解决**：
```bash
# 启动 Python AI 服务
cd python-ai-service
python main_simple.py
```
