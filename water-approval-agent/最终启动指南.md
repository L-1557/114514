## 🚀 快速启动（3 步）

### 步骤 1：启动 Python AI 服务

打开命令行，运行：
```bash
cd python-ai-service
python main_simple.py
```

**服务地址**: http://localhost:8001

### 步骤 2：安装 Maven（仅首次）

#### 方法 A：使用 Chocolatey（最简单）
```bash
choco install maven
```

#### 方法 B：手动安装
1. 下载：https://maven.apache.org/download.cgi
2. 解压到：`C:\Program Files\Apache\Maven`
3. 添加环境变量：`C:\Program Files\Apache\Maven\bin`

#### 方法 C：使用 IDE（无需安装 Maven）
- **IntelliJ IDEA**: 打开 `java-backend` 文件夹，运行 `WaterApprovalApplication.java`
- **Eclipse**: Import Maven Project，运行 `WaterApprovalApplication.java`

### 步骤 3：启动 Java 后端

安装 Maven 后，运行：
```bash
cd java-backend
mvn spring-boot:run
```

**服务地址**: http://localhost:8080

## 🔧 故障排除

### 问题 1：Python 服务无法启动
**解决**: 
- 检查端口 8001 是否被占用
- 修改 `main_simple.py` 中的 `PORT` 变量

### 问题 2：Java 后端无法启动
**解决**:
- 确保已安装 JDK 17+
- 确保已安装 Maven
- 检查环境变量配置

### 问题 3：Maven 下载慢
**解决**:
- 使用国内镜像：https://mirrors.aliyun.com/maven/
- 配置 `settings.xml` 使用阿里云镜像
