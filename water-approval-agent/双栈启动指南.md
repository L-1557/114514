## 📋 启动 Java 后端的 3 种方法

### 方法 1：使用 IntelliJ IDEA（推荐⭐⭐⭐）

**最简单，5 分钟内完成**

#### 步骤：

1. **打开 IntelliJ IDEA**

2. **导入项目**
   ```
   File → Open
   选择：c:\Users\吕浩宇\Desktop\新建文件夹\water-approval-agent\java-backend
   ```

3. **等待 Maven 自动导入**
   - IDEA 会自动识别 Maven 项目
   - 等待右下角进度条完成

4. **运行应用**

   - 访问：http://localhost:8080/api/health

---

### 方法 3：安装 Maven

#### 快速安装（使用 Chocolatey）：
```bash
choco install maven
```

#### 手动安装：

1. **下载 Maven**
   - 访问：https://maven.apache.org/download.cgi
   - 下载：`apache-maven-3.9.6-bin.zip`

2. **解压**
   - 解压到：`C:\Program Files\Apache\Maven`

3. **配置环境变量**
   - 右键"此电脑" → "属性"
   - "高级系统设置" → "环境变量"
   - 新建系统变量：
     - 变量名：`MAVEN_HOME`
     - 变量值：`C:\Program Files\Apache\Maven`
   - 编辑 Path，添加：`%MAVEN_HOME%\bin`

4. **验证**
   ```bash
   mvn -version
   ```

5. **启动**
   ```bash
   cd water-approval-agent\java-backend
   mvn spring-boot:run
   ```

## 📝 常见问题

### Q: IntelliJ IDEA 提示找不到 JDK？
**A**: 
1. File → Project Structure
2. SDKs → Add JDK
3. 选择 JDK 17+ 安装目录

### Q: Maven 下载依赖很慢？
**A**: 配置阿里云镜像
编辑 `pom.xml`，添加：
```xml
<mirrors>
    <mirror>
        <id>aliyun</id>
        <url>https://maven.aliyun.com/repository/public</url>
        <mirrorOf>central</mirrorOf>
    </mirror>
</mirrors>
```

### Q: 端口 8080 被占用？
**A**: 
1. 修改 `application.properties`
2. 将 `server.port=8080` 改为其他端口

### Q: Python 服务无法启动？
**A**: 
- 检查端口 8001 是否被占用
- 确认 Python 3.12+ 已安装
