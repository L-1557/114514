# 部署说明

## 系统要求

### 硬件要求
- **CPU**: 4 核以上（推荐 8 核）
- **内存**: 8GB 以上（推荐 16GB）
- **硬盘**: 10GB 可用空间
- **网络**: 本地回环网络

### 软件要求

#### Java 后端
- **JDK**: 17 或更高版本
- **Maven**: 3.8+
- **操作系统**: Windows 10/11, Linux, macOS

#### Python AI 服务
- **Python**: 3.9 或更高版本
- **pip**: 21.0+
- **Tesseract OCR**: 5.0+（用于 OCR 功能）
- **操作系统**: Windows 10/11, Linux, macOS

## 安装步骤

### 1. 安装 Java 环境

#### Windows
```bash
# 下载并安装 JDK 17
# 下载地址：https://www.oracle.com/java/technologies/downloads/

# 验证安装
java -version
# 应显示：java version "17.x.x"

# 设置 JAVA_HOME 环境变量
# 系统属性 → 高级 → 环境变量 → 新建系统变量
# 变量名：JAVA_HOME
# 变量值：C:\Program Files\Java\jdk-17
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install openjdk-17-jdk
java -version
```

### 2. 安装 Maven

#### Windows
```bash
# 下载 Maven
# 下载地址：https://maven.apache.org/download.cgi

# 解压到 C:\Program Files\Maven

# 设置 MAVEN_HOME 环境变量
# 将 %MAVEN_HOME%\bin 添加到 PATH

# 验证安装
mvn -version
```

#### Linux
```bash
sudo apt install maven
mvn -version
```

### 3. 安装 Python 环境

#### Windows
```bash
# 下载并安装 Python 3.9+
# 下载地址：https://www.python.org/downloads/

# 安装时勾选 "Add Python to PATH"

# 验证安装
python --version
# 应显示：Python 3.9.x
pip --version
```

#### Linux
```bash
sudo apt install python3 python3-pip python3-venv
python3 --version
```

### 4. 安装 Tesseract OCR（可选，用于 OCR 功能）

#### Windows
```bash
# 下载 Tesseract 安装程序
# 下载地址：https://github.com/UB-Mannheim/tesseract/wiki

# 安装时选择中文语言包

# 设置 TESSDATA_PREFIX 环境变量
# 变量值：C:\Program Files\Tesseract-OCR\tessdata

# 验证安装
tesseract --version
```

#### Linux
```bash
sudo apt install tesseract-ocr
sudo apt install libtesseract-dev

# 安装中文语言包
sudo apt install tesseract-ocr-chi-sim tesseract-ocr-chi-tra

# 验证安装
tesseract --version
```

## 生产环境部署

### 1. 使用 Docker 部署（推荐）

#### 创建 Dockerfile（Python）

```dockerfile
FROM python:3.9-slim

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    tesseract-ocr \
    libtesseract-dev \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app
COPY python-ai-service/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY python-ai-service/ .

EXPOSE 8000
CMD ["python", "main_enhanced.py"]
```

#### 创建 Dockerfile（Java）

```dockerfile
FROM maven:3.8-openjdk-17 AS build
WORKDIR /app
COPY java-backend/ .
RUN mvn clean package -DskipTests

FROM openjdk:17-slim
WORKDIR /app
COPY --from=build /app/target/*.jar app.jar

EXPOSE 8080
CMD ["java", "-jar", "app.jar"]
```

#### 创建 docker-compose.yml

```yaml
version: '3.8'

services:
  python-ai:
    build:
      context: .
      dockerfile: Dockerfile.python
    ports:
      - "8000:8000"
    volumes:
      - ./knowledge_base:/app/knowledge_base
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY}

  java-backend:
    build:
      context: .
      dockerfile: Dockerfile.java
    ports:
      - "8080:8080"
    environment:
      - PYTHON_AI_SERVICE_URL=http://python-ai:8000
    depends_on:
      - python-ai

volumes:
  knowledge_base:
```

#### 启动 Docker

```bash
docker-compose up -d
```

### 2. 使用 Nginx 反向代理

#### 安装 Nginx

```bash
# Ubuntu/Debian
sudo apt install nginx

# Windows
# 下载：http://nginx.org/en/download.html
```

#### 配置 Nginx

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # Java 后端
    location /api/ {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # Python AI 服务（可选，直接访问）
    location /ai/ {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

#### 重启 Nginx

```bash
sudo systemctl restart nginx
```

## 故障排查

### 常见问题

#### 1. Python 服务无法启动

**症状**: 端口被占用
```bash
# Windows: 查找占用端口的进程
netstat -ano | findstr :8000

# 杀死进程
taskkill /PID <PID> /F

# Linux
lsof -i :8000
kill -9 <PID>
```

#### 2. Java 后端连接不上 Python 服务

**检查**:
```bash
# 检查 Python 服务是否运行
curl http://localhost:8000/api/health

# 检查配置文件
cat java-backend/src/main/resources/application.properties | grep python.ai.service.url
```

#### 3. OCR 功能不可用

**检查**:
```bash
# 检查 Tesseract 安装
tesseract --version

# 检查语言包
tesseract --list-langs

# 检查环境变量
echo $TESSDATA_PREFIX  # Linux
echo %TESSDATA_PREFIX%  # Windows
```

#### 4. 内存不足

**解决**:
```bash
# Python: 减少 batch size
# Java: 调整 JVM 参数
java -Xms256m -Xmx1g -jar app.jar
```
