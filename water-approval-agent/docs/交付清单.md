✅ **双栈开发**：Java + Python 协同开发

✅ **架构模式**：前后端分离架构

✅ **知识库构建**：
- ✅ 使用 ChromaDB 作为向量数据库

✅ **MCP 协议实现**：

✅ **Agent 智能体**：
