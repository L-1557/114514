# 涉水审批材料合规性审查Agent系统 - 实践报告

## 一、技术方案

### 1.1 系统架构设计

本系统采用双栈架构（Java + Python），实现前后端分离和AI工程化集成。

#### 架构图
```
┌─────────────────┐    HTTP/MCP     ┌─────────────────┐
│   前端界面       │ ◄─────────────► │  Java Spring    │
│   (浏览器)       │                 │  Boot Backend   │
└─────────────────┘                 └────────┬────────┘
                                             │
                                      HTTP   │
                                             ▼
                               ┌─────────────────┐
                               │  Python AI      │
                               │  FastAPI +      │
                               │  LangChain      │
                               └────────┬────────┘
                                        │
                                 ChromaDB│
                                        ▼
                               ┌─────────────────┐
                               │  向量知识库      │
                               │  (法规文档)      │
                               └─────────────────┘
```

### 1.2 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 主后端 | Java Spring Boot 3.2 | 提供REST API，业务逻辑处理 |
| AI服务 | Python FastAPI | AI模型服务，Agent执行 |
| AI框架 | LangChain | Agent智能体构建 |
| 向量数据库 | ChromaDB | 文档向量化存储 |
| Embedding模型 | text2vec-base-chinese | 中文文本向量化 |
| 文档解析 | PyPDF, Docx2txt | PDF/Word文档处理 |
| 协议 | MCP | 标准化工具调用协议 |

### 1.3 核心功能模块

1. **形式审查模块**：检查申请材料完整性
2. **内容规范模块**：验证表单数据逻辑
3. **合规审查模块**：基于RAG的法规合规性检查
4. **MCP工具模块**：knowledge_search和check_completeness

## 二、实现过程

### 2.1 Python AI服务实现

#### 2.1.1 知识库构建
```python
# 初始化ChromaDB和Embedding模型
self.embeddings = HuggingFaceEmbeddings(
    model_name="shibing624/text2vec-base-chinese"
)
self.chroma_client = chromadb.PersistentClient(path=knowledge_base_path)
```

#### 2.1.2 MCP工具实现
- `knowledge_search`：搜索法规知识库
- `check_completeness`：检查材料完整性

#### 2.1.3 Agent智能体
使用LangChain的Zero-Shot Agent，结合MCP工具实现智能审查。

### 2.2 Java后端实现

#### 2.2.1 Spring Boot配置
- CORS跨域支持
- WebClient调用Python服务
- RESTful API设计

#### 2.2.2 核心接口
- POST /api/review：提交审查请求
- GET /api/health：健康检查

### 2.3 双栈通信

Java后端通过HTTP调用Python AI服务：
```java
return webClient.post()
    .uri("/api/review")
    .bodyValue(request)
    .retrieve()
    .bodyToMono(ReviewResponse.class);
```
