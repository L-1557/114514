# 涉水审批材料合规性审查Agent系统 - 运行说明

## 环境要求

### Python环境
- Python 3.8+
- pip包管理器

### Java环境
- JDK 17+
- Maven 3.6+

## 快速启动

### 1. 启动Python AI服务

```bash
# Windows
start-python.bat

# 或手动启动
cd python-ai-service
pip install -r requirements.txt
python main.py
```

服务地址：http://localhost:8000

### 2. 启动Java后端

```bash
# Windows
start-java.bat

# 或手动启动
cd java-backend
mvn spring-boot:run
```

服务地址：http://localhost:8080

## 配置说明

### Python服务配置
- 设置环境变量 `OPENAI_API_KEY` 用于LLM调用
- ChromaDB数据存储在 `python-ai-service/knowledge_base` 目录

### Java服务配置
- 配置文件：`java-backend/src/main/resources/application.properties`
- 默认端口：8080
- Python服务地址：http://localhost:8000

## 常见问题

### Q: Python依赖安装失败
A: 确保使用Python 3.8+，可尝试使用虚拟环境

### Q: Java编译错误
A: 确保JDK版本为17+，Maven版本为3.6+

### Q: 服务无法启动
A: 检查端口是否被占用，查看日志获取详细错误信息
