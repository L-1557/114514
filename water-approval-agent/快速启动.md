## 🚀 快速启动

### 方式一：使用简化版 Python 服务（推荐 - 无需安装依赖）

1. **启动 Python AI 服务**
   ```bash
   cd python-ai-service
   python main_simple.py
   ```
   服务地址：http://localhost:8001

2. **测试服务**（新终端）
   ```bash
   python -c "import urllib.request; print(urllib.request.urlopen('http://localhost:8001/api/health').read().decode())"
   ```

3. **测试审查功能**
   ```bash
   python test_system.py
   ```

### 方式二：使用完整版 Python 服务（需要安装依赖）

1. **安装依赖**
   ```bash
   cd python-ai-service
   pip install -r requirements.txt
   ```
   或使用批处理文件：
   ```bash
   install-deps.bat
   ```

2. **启动服务**
   ```bash
   python main.py
   ```
   服务地址：http://localhost:8000

### 启动 Java 后端

1. **确保 Python 服务已启动**

2. **启动 Java 后端**
   ```bash
   cd java-backend
   mvn spring-boot:run
   ```
   或使用批处理文件：
   ```bash
   start-java.bat
   ```
   服务地址：http://localhost:8080

## 📝 常见问题

### Q: Python 服务无法启动？
A: 使用简化版 `main_simple.py`，无需任何外部依赖。

### Q: 端口被占用？
A: 修改 `main_simple.py` 中的 `PORT` 变量。

### Q: Java 后端无法连接 Python 服务？
A: 确保 Python 服务已启动，检查 `application.properties` 中的端口配置。

### Q: 如何安装完整依赖？
A: 运行 `python-ai-service/install-deps.bat` 或手动执行 `pip install -r requirements.txt`。
