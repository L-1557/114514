## 🌐 API 接口

### 1. 上传单个文件
```http
POST /api/files/upload
Content-Type: multipart/form-data

参数：
- file: 文件（必填）
- applicationId: 关联的申请 ID（可选）
```

**响应示例**：
```json
{
  "status": "success",
  "message": "上传成功",
  "data": {
    "id": 1,
    "fileName": "abc123.pdf",
    "originalName": "测试文件.pdf",
    "contentType": "application/pdf",
    "size": 102400,
    "sizeFormatted": "100.00 KB",
    "uploadTime": "2024-01-01T12:00:00",
    "downloadUrl": "/api/files/abc123.pdf"
  }
}
```

### 2. 上传多个文件
```http
POST /api/files/uploads
Content-Type: multipart/form-data

参数：
- files: 文件数组（必填）
- applicationId: 关联的申请 ID（可选）
```

### 3. 下载文件
```http
GET /api/files/{fileName}
```

**响应**：文件下载（附件形式）

### 4. 预览文件
```http
GET /api/files/preview/{fileName}
```

**响应**：文件预览（内联显示，适合 PDF、图片）

### 5. 获取文件列表
```http
GET /api/files/application/{applicationId}
```

**响应**：该申请的所有文件列表

### 6. 获取文件信息
```http
GET /api/files/info/{id}
```

**响应**：单个文件的详细信息

### 7. 删除文件
```http
DELETE /api/files/{id}
```

**响应**：删除成功/失败

## 📂 文件存储

### 存储位置
```
java-backend/uploads/
```

### 文件命名规则
```
{UUID}.{扩展名}
```
例如：`550e8400e29b41d495dd68e8b35ac3b1.pdf`

### 数据库表结构
```sql
CREATE TABLE files (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    file_name VARCHAR(255) NOT NULL,          -- UUID 文件名
    original_name VARCHAR(255) NOT NULL,       -- 原始文件名
    content_type VARCHAR(100) NOT NULL,        -- MIME 类型
    file_size BIGINT NOT NULL,                 -- 文件大小（字节）
    file_path VARCHAR(500) NOT NULL,           -- 文件路径
    application_id BIGINT,                     -- 关联的申请 ID
    description VARCHAR(500),                  -- 文件描述
    upload_time TIMESTAMP NOT NULL,            -- 上传时间
    upload_ip VARCHAR(50),                     -- 上传 IP
    download_count INT DEFAULT 0,              -- 下载次数
    is_deleted BOOLEAN DEFAULT FALSE           -- 删除标记
);
```

## 🚀 使用流程

### 1. 上传文件

**前端操作**：
1. 打开"新建申请"页面
2. 找到"上传附件"区域
3. 点击或拖拽文件
4. 等待上传完成
5. 查看文件列表

**后端处理**：
1. 接收文件
2. 验证文件（类型、大小）
3. 生成唯一文件名
4. 保存文件到 `uploads/` 目录
5. 保存文件信息到数据库
6. 返回文件信息

### 2. 下载文件

**前端操作**：
1. 在文件列表中点击"下载"链接
2. 浏览器开始下载

**后端处理**：
1. 根据文件名查找文件信息
2. 增加下载次数
3. 返回文件流

### 3. 删除文件

**前端操作**：
1. 在文件列表中点击"删除"按钮
2. 确认删除
3. 从列表中移除

**后端处理**：
1. 根据 ID 查找文件
2. 删除物理文件
3. 更新数据库记录（标记为已删除）

##  常见问题

### Q1: 上传目录在哪里？
A: `java-backend/uploads/` 目录，首次上传会自动创建。

### Q2: 文件存储在数据库中吗？
A: 文件信息存储在数据库中，文件内容存储在服务器文件系统中。

### Q3: 如何查看已上传的文件？
A: 
- 方法 1：直接访问 `uploads/` 目录
- 方法 2：通过 API 接口 `/api/files/application/{applicationId}`
- 方法 3：在前端查看申请详情

### Q4: 重启服务后文件会丢失吗？
A: 不会，文件存储在磁盘中，重启后仍然存在。

### Q5: 如何备份文件？
A: 定期备份 `uploads/` 目录即可。
